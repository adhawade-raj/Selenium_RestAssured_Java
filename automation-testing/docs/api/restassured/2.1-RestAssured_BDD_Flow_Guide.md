## Step 1: Test Runner

**File Location:** `src/test/java/runner/RunCucumberTests.java`

**Purpose:** Entry point that tells Cucumber where to find feature files, step definitions, and hooks.

```java
package runner;

import org.junit.platform.suite.api.*;
import static io.cucumber.junit.platform.engine.Constants.*;

@Suite
@IncludeEngines("cucumber")
@SelectClasspathResource("features")
@ConfigurationParameter(key = GLUE_PROPERTY_NAME, value = "steps,hooks")
@ConfigurationParameter(
    key = PLUGIN_PROPERTY_NAME, 
    value = "pretty,json:target/cucumber.json,html:target/cucumber-report.html,io.qameta.allure.cucumber7jvm.AllureCucumber7Jvm"
)
@ConfigurationParameter(key = FILTER_TAGS_PROPERTY_NAME, value = "@smoke or @regression")
public class RunCucumberTests {
}
```

**Key Configuration:**
- `features` → Scans src/test/resources/features for .feature files
- `steps,hooks` → Glue path where step definitions and hooks are located
- `@smoke or @regression` → Filter which scenarios to run by tags
- Allure plugin for advanced reporting

**Run from Command Line:**
```bash
# Run all scenarios
mvn clean test

# Run specific tag
mvn clean test -Dcucumber.filter.tags="@smoke"

# Run specific environment
mvn clean test -Denv=QA -Dcucumber.filter.tags="@user-creation"
```

## Step 2: Feature Files

**File Location:** `src/test/resources/features/`

**Purpose:** Human-readable test scenarios in Gherkin language (Given-When-Then)

### Example 1: Simple Scenario

**File:** `user_management.feature`

```gherkin
@user-management @smoke
Feature: User Management API
  
  As a QA Engineer
  I want to test user creation and retrieval
  So that I can validate the API functionality

  @create-user
  Scenario: Create a single user successfully
    Given the base URL is "https://api.qa.com"
    And I have a new user with:
      | name  | John Doe            |
      | email | john@example.com    |
      | role  | admin               |
    When I send a POST request to "/users"
    Then the response status code should be 201
    And the response contains user id
    And the user name should be "John Doe"

  @get-users
  Scenario: Retrieve all users
    Given the base URL is "https://api.qa.com"
    When I send a GET request to "/users"
    Then the response status code should be 200
    And the response contains a list of users
    And the response list should have at least 1 user
```

## Step 3: Step Definitions

**File Location:** `src/test/java/steps/`

**Purpose:** Implements the Gherkin steps from feature files in Java

### Example: UserStepDefinitions.java

```java
package steps;

import io.cucumber.java.en.*;
import io.restassured.response.Response;
import context.TestContext;
import utils.ConfigReader;
import utils.JsonPathUtil;

public class UserStepDefinitions {

    private TestContext context;
    private Response lastResponse;
    private String baseUrl;

    // Constructor for dependency injection (PicoContainer)
    public UserStepDefinitions(TestContext context) {
        this.context = context;
    }

    // ==================== GIVEN Steps ====================

    @Given("the base URL is {string}")
    public void setBaseUrl(String url) {
        this.baseUrl = url;
        // Initialize RestClient with dynamic base URL
        context.initializeRestClient(url);
        System.out.println("✓ Base URL set to: " + url);
    }

    @Given("I have a new user with:")
    public void prepareUserData(io.cucumber.datatable.DataTable dataTable) {
        Map<String, String> userDataMap = dataTable.asMap();
        
        // Create user object from data table
        User user = new User();
        user.setName(userDataMap.get("name"));
        user.setEmail(userDataMap.get("email"));
        user.setRole(userDataMap.get("role"));
        
        // Store in context for later use
        context.setTestData("currentUser", user);
        System.out.println("✓ User prepared: " + user.getName() + " (" + user.getEmail() + ")");
    }

    @Given("I load test data from {string}")
    public void loadTestData(String fileName) {
        String testDataPath = context.getConfigManager().getTestDataPath();
        Map<String, Object> testData = JsonPathUtil.loadTestData(testDataPath + fileName);
        context.setTestData("testDataFile", testData);
        System.out.println("✓ Test data loaded from: " + fileName);
    }

    // ==================== WHEN Steps ====================

    @When("I send a POST request to {string}")
    public void sendPostRequest(String endpoint) {
        User user = (User) context.getTestData("currentUser");
        
        // Call RestClient to execute POST
        lastResponse = context.getRestClient().post(
            endpoint,
            "application/json",
            user,
            true,  // includeAuth
            true   // logResponse
        );
        
        // Store response in context
        context.setLastResponse(lastResponse);
        System.out.println("✓ POST request sent to: " + endpoint);
        System.out.println("  Response Status: " + lastResponse.getStatusCode());
    }

    @When("I send a GET request to {string}")
    public void sendGetRequest(String endpoint) {
        lastResponse = context.getRestClient().get(
            endpoint,
            true,  // includeAuth
            true   // logResponse
        );
        
        context.setLastResponse(lastResponse);
        System.out.println("✓ GET request sent to: " + endpoint);
        System.out.println("  Response Status: " + lastResponse.getStatusCode());
    }

    @When("I create users for testcase {string}")
    public void createUsersForTestcase(String testcaseId) {
        Map<String, Object> testDataFile = (Map<String, Object>) context.getTestData("testDataFile");
        Map<String, Object> testcaseData = (Map<String, Object>) testDataFile.get(testcaseId);
        
        List<User> users = (List<User>) testcaseData.get("users");
        
        for (User user : users) {
            Response response = context.getRestClient().post(
                "/users",
                "application/json",
                user,
                true,
                false
            );
            context.setLastResponse(response);
        }
        System.out.println("✓ Created " + users.size() + " users for testcase: " + testcaseId);
    }

    // ==================== THEN Steps ====================

    @Then("the response status code should be {int}")
    public void verifyStatusCode(int expectedCode) {
        int actualCode = lastResponse.getStatusCode();
        assert actualCode == expectedCode : 
            "Expected status " + expectedCode + " but got " + actualCode;
        System.out.println("✓ Status code verified: " + actualCode);
    }

    @Then("the response contains user id")
    public void verifyUserIdInResponse() {
        String userId = lastResponse.jsonPath().getString("id");
        assert userId != null && !userId.isEmpty() : 
            "User ID not found in response";
        context.setTestData("lastCreatedUserId", userId);
        System.out.println("✓ User ID found in response: " + userId);
    }

    @Then("the user name should be {string}")
    public void verifyUserName(String expectedName) {
        String actualName = lastResponse.jsonPath().getString("name");
        assert actualName.equals(expectedName) : 
            "Expected name " + expectedName + " but got " + actualName;
        System.out.println("✓ User name verified: " + actualName);
    }

    @Then("the response contains a list of users")
    public void verifyUsersList() {
        List<?> usersList = lastResponse.jsonPath().getList("$");
        assert usersList != null && !usersList.isEmpty() : 
            "Users list is empty or null";
        System.out.println("✓ Users list verified: " + usersList.size() + " users found");
    }

    @Then("the response list should have at least {int} user")
    public void verifyMinimumUserCount(int minCount) {
        List<?> usersList = lastResponse.jsonPath().getList("$");
        assert usersList.size() >= minCount : 
            "Expected at least " + minCount + " users but got " + usersList.size();
        System.out.println("✓ Minimum user count verified: " + usersList.size() + " users");
    }

    @Then("all users should be created successfully")
    public void verifyAllUsersCreated() {
        int statusCode = lastResponse.getStatusCode();
        assert statusCode >= 200 && statusCode < 300 : 
            "Request failed with status: " + statusCode;
        System.out.println("✓ All users created successfully");
    }
}
```

## Step 4: RestClient Layer

**File Location:** `src/main/java/client/RestClient.java`

**Purpose:** Handles all HTTP communication using RestAssured

```java
package client;

import io.restassured.RestAssured;
import io.restassured.response.Response;
import io.restassured.specification.RequestSpecification;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class RestClient {
    
    private static final Logger logger = LoggerFactory.getLogger(RestClient.class);
    private RequestSpecification requestSpec;
    private String baseURI;
    private String token;

    public RestClient(String baseURI) {
        this.baseURI = baseURI;
        RestAssured.baseURI = baseURI;
        this.requestSpec = RestAssured.given();
    }

    // ==================== GET Requests ====================

    public Response get(String endpoint, boolean includeAuth, boolean logResponse) {
        RequestSpecification spec = buildSpec(includeAuth);
        
        logger.info("GET Request: " + baseURI + endpoint);
        Response response = spec.when().get(endpoint);
        
        if (logResponse) {
            logResponse(response);
        }
        return response;
    }

    // ==================== POST Requests ====================

    public Response post(String endpoint, String contentType, Object body, 
                        boolean includeAuth, boolean logResponse) {
        RequestSpecification spec = buildSpec(includeAuth)
            .contentType(contentType)
            .body(body);
        
        logger.info("POST Request: " + baseURI + endpoint);
        logger.info("Request Body: " + body);
        Response response = spec.when().post(endpoint);
        
        if (logResponse) {
            logResponse(response);
        }
        return response;
    }

    // ==================== PUT Requests ====================

    public Response put(String endpoint, String contentType, Object body, 
                       boolean includeAuth, boolean logResponse) {
        RequestSpecification spec = buildSpec(includeAuth)
            .contentType(contentType)
            .body(body);
        
        logger.info("PUT Request: " + baseURI + endpoint);
        Response response = spec.when().put(endpoint);
        
        if (logResponse) {
            logResponse(response);
        }
        return response;
    }

    // ==================== DELETE Requests ====================

    public Response delete(String endpoint, boolean includeAuth, boolean logResponse) {
        RequestSpecification spec = buildSpec(includeAuth);
        
        logger.info("DELETE Request: " + baseURI + endpoint);
        Response response = spec.when().delete(endpoint);
        
        if (logResponse) {
            logResponse(response);
        }
        return response;
    }

    // ==================== Helper Methods ====================

    private RequestSpecification buildSpec(boolean includeAuth) {
        RequestSpecification spec = RestAssured.given();
        
        if (includeAuth && token != null) {
            spec.header("Authorization", "Bearer " + token);
        }
        
        spec.header("Accept", "application/json")
            .header("Content-Type", "application/json");
        
        return spec;
    }

    private void logResponse(Response response) {
        logger.info("Response Status: " + response.getStatusCode());
        logger.info("Response Body: " + response.getBody().asString());
        logger.info("Response Time: " + response.getTime() + "ms");
    }

    public void setAuthToken(String token) {
        this.token = token;
    }

    public void setBaseURI(String baseURI) {
        this.baseURI = baseURI;
        RestAssured.baseURI = baseURI;
    }
}
```

### 5.1 ConfigurationManager

**File:** `src/main/java/config/ConfigurationManager.java`

```java
package config;

import java.io.InputStream;
import java.util.Properties;

public class ConfigurationManager {
    
    private static Properties props;
    private String env;
    private String channel;

    public ConfigurationManager() {
        initProperties();
    }

    private void initProperties() {
        props = new Properties();
        String envName = System.getProperty("env", "qa");
        
        try (InputStream is = getClass().getClassLoader()
                .getResourceAsStream("config/application-" + envName + ".properties")) {
            props.load(is);
            this.env = envName;
            this.channel = props.getProperty("test.data.channel", "MOB");
        } catch (Exception e) {
            throw new RuntimeException("Failed to load config: " + envName, e);
        }
    }

    public String getProperty(String key) {
        return props.getProperty(key);
    }

    public String getTestDataPath() {
        return "src/test/resources/testdata/" + env + "/" + channel + "/";
    }

    public String getEnvironment() {
        return env;
    }

    public String getChannel() {
        return channel;
    }
}
```

package utils;

import com.jayway.jsonpath.JsonPath;
import java.nio.file.Files;
import java.nio.file.Paths;
import java.util.Map;

public class JsonPathUtil {
    
    public static Map<String, Object> loadTestData(String filePath) {
        try {
            String content = new String(Files.readAllBytes(Paths.get(filePath)));
            return JsonPath.read(content, "$");
        } catch (Exception e) {
            throw new RuntimeException("Failed to load test data: " + filePath, e);
        }
    }

    public static Object getValueByJsonPath(String response, String jsonPath) {
        try {
            return JsonPath.read(response, jsonPath);
        } catch (Exception e) {
            throw new RuntimeException("Failed to parse JSON path: " + jsonPath, e);
        }
    }

    public static String getEndpoint(Map<String, Object> testData, String testcaseId) {
        return (String) ((Map<String, Object>) testData.get(testcaseId)).get("endpoint");
    }

    public static String getMethod(Map<String, Object> testData, String testcaseId) {
        return (String) ((Map<String, Object>) testData.get(testcaseId)).get("method");
    }

    public static int getExpectedStatus(Map<String, Object> testData, String testcaseId) {
        return (int) ((Map<String, Object>) testData.get(testcaseId)).get("statusCode");
    }
}

package context;

import client.RestClient;
import config.ConfigurationManager;
import io.restassured.response.Response;
import java.util.HashMap;
import java.util.Map;

public class TestContext {
    
    private RestClient restClient;
    private Response lastResponse;
    private String authToken;
    private Map<String, Object> testData = new HashMap<>();
    private ConfigurationManager configManager;

    public TestContext() {
        this.configManager = new ConfigurationManager();
    }

    public void initializeRestClient(String baseUrl) {
        this.restClient = new RestClient(baseUrl);
        if (authToken != null) {
            restClient.setAuthToken(authToken);
        }
    }

    public RestClient getRestClient() {
        return restClient;
    }

    public void setLastResponse(Response response) {
        this.lastResponse = response;
    }

    public Response getLastResponse() {
        return lastResponse;
    }

    public void setAuthToken(String token) {
        this.authToken = token;
        if (restClient != null) {
            restClient.setAuthToken(token);
        }
    }

    public void setTestData(String key, Object value) {
        testData.put(key, value);
    }

    public Object getTestData(String key) {
        return testData.get(key);
    }

    public ConfigurationManager getConfigManager() {
        return configManager;
    }

## Execution Example

### Scenario Run Flow

```
1. USER: mvn clean test -Dcucumber.filter.tags="@create-user"
   ↓
2. RUNNER: RunCucumberTests.java loads features and step definitions
   ↓
3. FEATURE: user_management.feature → "Create a single user successfully"
   ↓
4. STEP 1: @Given("the base URL is ...") 
   → UserStepDefinitions.setBaseUrl("https://api.qa.com")
   ↓
5. STEP 2: @Given("I have a new user with:")
   → UserStepDefinitions.prepareUserData(dataTable)
   → Stores User object in TestContext
   ↓
6. STEP 3: @When("I send a POST request to ...")
   → UserStepDefinitions.sendPostRequest("/users")
   → Calls RestClient.post()
   → RestClient makes HTTP request via RestAssured
   → Response stored in TestContext
   ↓
7. STEP 4: @Then("the response status code should be 201")
   → UserStepDefinitions.verifyStatusCode(201)
   → Retrieves response from TestContext
   → Asserts status code
   ↓
8. STEP 5: @Then("the response contains user id")
   → UserStepDefinitions.verifyUserIdInResponse()
   → Uses JsonPath to extract user ID from response
   → Stores in TestContext for future steps
   ↓
9. REPORT: Test result logged to console and Allure report
```

## Key Takeaways

| Component | Purpose | Key Responsibility |
|-----------|---------|-------------------|
| **Runner** | Entry point | Discovers & executes feature files |
| **Feature Files** | Test specification | Human-readable test scenarios |
| **Step Definitions** | Glue code | Maps Gherkin to Java logic |
| **RestClient** | HTTP layer | Executes REST API calls |
| **TestContext** | Shared state | Holds data across steps |
| **ConfigurationManager** | Settings | Loads environment properties |
| **Utilities** | Helper functions | JSON parsing, data loading, etc. |
