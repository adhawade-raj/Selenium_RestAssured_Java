# Automation Framework — Architecture, Tech Stack & Flow

Interview-ready notes based on the supplied framework diagram

The major components below are transcribed and organized from the supplied architecture image.

## 1. Framework Overview

The framework is a hybrid Java UI automation framework combining Page Object Model (POM), layered/DDD-style separation, reusable utilities, centralized configuration, data-driven testing, TestNG execution, reporting/logging and CI/CD.

- **Language:** Java
- **UI automation:** Selenium WebDriver
- **Design approach:** Hybrid framework + POM + layered/DDD-style organization
- **Test execution:** TestNG
- **Build/dependency management:** Maven
- **Configuration:** properties files with environment/browser values
- **Test data:** Excel/XLSX
- **CI/CD:** Jenkins
- **Source/artifact ecosystem:** Git + Nexus
- **Distributed execution:** Dockerized Selenium Grid / remote nodes; AWS infrastructure is shown
- **Reporting/logging:** TestNG reports, Extent/Allure-style reporting, logs and screenshots

## 2. High-Level Architecture Flow

The framework follows a layered architecture with clear separation of concerns from test execution through to reporting and infrastructure.

## 3. Layer-by-Layer Explanation

| Layer | What it contains | Interview explanation |
|-------|-----------------|----------------------|
| **Page Layer** | LoginPage, AccPage, ResultsPage, ProductInfoPage, RegPage, etc. | Encapsulates locators and page-specific actions so tests do not directly contain UI details. |
| **DriverFactory** | Local/remote WebDriver creation | Centralizes browser/driver creation and allows switching between local and grid execution. |
| **Config Properties** | URL, browser, environment and runtime flags | Externalizes environment-specific values and avoids hardcoding. |
| **Test Layer** | Test classes, test methods, assertions | Contains business scenarios and expected-result validation. |
| **BaseTest** | Common setup and teardown | Provides common lifecycle operations and reduces duplicate setup code. |
| **Utility Layer** | Element/JS utilities, Excel utility, constants, error handling | Provides reusable support functions across tests and pages. |
| **Test Data Layer** | Excel/XLSX | Separates input data from test logic and supports data-driven execution. |
| **Test Runner** | TestNG XML suites such as sanity/regression/master | Controls which tests run and can be selected from CI. |
| **Reports & Logs** | TestNG/Extent/Allure-style reports, logs, screenshots | Provides execution evidence and helps diagnose failures. |
| **CI/CD** | Jenkins jobs/pipeline | Triggers builds, passes runtime parameters, executes suites and publishes results. |
| **Execution Infrastructure** | Dockerized Selenium Grid, remote nodes, AWS | Supports remote and scalable browser execution. |
| **Repository / Artifacts** | Git and Nexus | Git manages source code; Nexus can manage build artifacts/snapshots. |

## 3.1 Code Examples

### 1. DriverFactory — Local & Remote WebDriver Creation

```java
public class DriverFactory {
    
    public static WebDriver initDriver(String browser, String executionMode) {
        WebDriver driver = null;
        
        if (executionMode.equalsIgnoreCase("local")) {
            switch (browser.toLowerCase()) {
                case "chrome":
                    driver = new ChromeDriver(getChromeOptions());
                    break;
                case "firefox":
                    driver = new FirefoxDriver(getFirefoxOptions());
                    break;
                case "safari":
                    driver = new SafariDriver();
                    break;
                case "edge":
                    driver = new EdgeDriver(getEdgeOptions());
                    break;
                default:
                    System.out.println("Browser not supported: " + browser);
            }
        } else if (executionMode.equalsIgnoreCase("remote")) {
            driver = initRemoteDriver(browser);
        }
        
        return driver;
    }
    
    private static WebDriver initRemoteDriver(String browser) {
        try {
            URL gridUrl = new URL("http://localhost:4444"); // Selenium Grid Hub URL
            Capabilities capabilities = new ChromeOptions();
            
            if (browser.equalsIgnoreCase("firefox")) {
                capabilities = new FirefoxOptions();
            }
            
            return new RemoteWebDriver(gridUrl, capabilities);
        } catch (MalformedURLException e) {
            System.out.println("Remote WebDriver initialization failed: " + e.getMessage());
            return null;
        }
    }
    
    private static ChromeOptions getChromeOptions() {
        ChromeOptions options = new ChromeOptions();
        options.addArguments("--start-maximized");
        options.addArguments("--disable-notifications");
        options.addArguments("--incognito");
        return options;
    }
    
    private static FirefoxOptions getFirefoxOptions() {
        FirefoxOptions options = new FirefoxOptions();
        options.addArguments("--start-maximized");
        return options;
    }
    
    private static EdgeOptions getEdgeOptions() {
        EdgeOptions options = new EdgeOptions();
        options.addArguments("--start-maximized");
        return options;
    }
}
```

### 2. ConfigurationManager — Environment & Browser Configuration

```java
public class ConfigurationManager {
    private Properties prop;
    private static ConfigurationManager configManager;
    
    private ConfigurationManager() {
        prop = new Properties();
        String propFile = "application-" + getEnvironment() + ".properties";
        
        try (InputStream input = getClass().getClassLoader()
                .getResourceAsStream(propFile)) {
            if (input != null) {
                prop.load(input);
            }
        } catch (IOException e) {
            System.out.println("Unable to load properties file: " + e.getMessage());
        }
    }
    
    public static ConfigurationManager getInstance() {
        if (configManager == null) {
            configManager = new ConfigurationManager();
        }
        return configManager;
    }
    
    public String getEnvironment() {
        return System.getProperty("env", "qa");
    }
    
    public String getBrowser() {
        return System.getProperty("browser", prop.getProperty("browser", "chrome"));
    }
    
    public String getExecutionMode() {
        return prop.getProperty("execution.mode", "local");
    }
    
    public String getApplicationUrl() {
        return prop.getProperty("app.url");
    }
    
    public int getExplicitWait() {
        return Integer.parseInt(prop.getProperty("explicit.wait", "10"));
    }
    
    public int getImplicitWait() {
        return Integer.parseInt(prop.getProperty("implicit.wait", "5"));
    }
    
    public int getPageLoadTimeout() {
        return Integer.parseInt(prop.getProperty("page.load.timeout", "20"));
    }
}
```

### 3. BaseTest — Common Setup & Teardown

```java
public class BaseTest {
    
    protected WebDriver driver;
    protected ConfigurationManager configManager;
    
    @BeforeTest
    @Parameters({"browser"})
    public void setUp(@Optional("chrome") String browser) {
        configManager = ConfigurationManager.getInstance();
        String executionMode = configManager.getExecutionMode();
        
        driver = DriverFactory.initDriver(browser, executionMode);
        driver.manage().window().maximize();
        driver.manage().timeouts().implicitlyWait(
            Duration.ofSeconds(configManager.getImplicitWait())
        );
        driver.manage().timeouts().pageLoadTimeout(
            Duration.ofSeconds(configManager.getPageLoadTimeout())
        );
        
        driver.get(configManager.getApplicationUrl());
    }
    
    @AfterTest
    public void tearDown() {
        if (driver != null) {
            driver.quit();
        }
    }
    
    @BeforeMethod
    public void beforeMethod(Method method) {
        System.out.println("Starting test: " + method.getName());
    }
    
    @AfterMethod
    public void afterMethod(ITestResult result) {
        if (ITestResult.FAILURE == result.getStatus()) {
            captureScreenshot(result.getName());
        }
    }
    
    protected void captureScreenshot(String testName) {
        TakesScreenshot ts = (TakesScreenshot) driver;
        File source = ts.getScreenshotAs(OutputType.FILE);
        String destination = "screenshots/" + testName + "_" + System.currentTimeMillis() + ".png";
        try {
            FileUtils.copyFile(source, new File(destination));
            System.out.println("Screenshot saved: " + destination);
        } catch (IOException e) {
            System.out.println("Failed to save screenshot: " + e.getMessage());
        }
    }
}
```

### 4. BasePage — Page Object Model Base Class

```java
public class BasePage {
    
    protected WebDriver driver;
    protected WebDriverWait wait;
    
    public BasePage(WebDriver driver) {
        this.driver = driver;
        this.wait = new WebDriverWait(driver, Duration.ofSeconds(
            ConfigurationManager.getInstance().getExplicitWait()
        ));
    }
    
    protected void waitForElementVisible(By locator) {
        wait.until(ExpectedConditions.visibilityOfElementLocated(locator));
    }
    
    protected void waitForElementClickable(By locator) {
        wait.until(ExpectedConditions.elementToBeClickable(locator));
    }
    
    protected void click(By locator) {
        waitForElementClickable(locator);
        driver.findElement(locator).click();
    }
    
    protected void sendKeys(By locator, String text) {
        waitForElementVisible(locator);
        driver.findElement(locator).clear();
        driver.findElement(locator).sendKeys(text);
    }
    
    protected String getText(By locator) {
        waitForElementVisible(locator);
        return driver.findElement(locator).getText();
    }
    
    protected void scrollToElement(By locator) {
        WebElement element = driver.findElement(locator);
        JavascriptExecutor js = (JavascriptExecutor) driver;
        js.executeScript("arguments[0].scrollIntoView(true);", element);
    }
    
    protected boolean isElementDisplayed(By locator) {
        try {
            return driver.findElement(locator).isDisplayed();
        } catch (NoSuchElementException e) {
            return false;
        }
    }
}
```

### 5. Page Object Example — LoginPage

```java
public class LoginPage extends BasePage {
    
    private By usernameField = By.id("username");
    private By passwordField = By.id("password");
    private By loginButton = By.xpath("//button[@type='submit']");
    private By errorMessage = By.className("error-message");
    
    public LoginPage(WebDriver driver) {
        super(driver);
    }
    
    public void enterUsername(String username) {
        sendKeys(usernameField, username);
    }
    
    public void enterPassword(String password) {
        sendKeys(passwordField, password);
    }
    
    public void clickLoginButton() {
        click(loginButton);
    }
    
    public String getErrorMessage() {
        return getText(errorMessage);
    }
    
    public boolean isErrorDisplayed() {
        return isElementDisplayed(errorMessage);
    }
    
    public DashboardPage login(String username, String password) {
        enterUsername(username);
        enterPassword(password);
        clickLoginButton();
        return new DashboardPage(driver);
    }
}
```

### 6. Utility Layer — WaitUtility

```java
public class WaitUtility {
    
    private WebDriver driver;
    private WebDriverWait wait;
    
    public WaitUtility(WebDriver driver, int timeoutInSeconds) {
        this.driver = driver;
        this.wait = new WebDriverWait(driver, Duration.ofSeconds(timeoutInSeconds));
    }
    
    public WebElement waitForElement(By locator) {
        return wait.until(ExpectedConditions.presenceOfElementLocated(locator));
    }
    
    public void waitForElementToBeClickable(By locator) {
        wait.until(ExpectedConditions.elementToBeClickable(locator));
    }
    
    public void waitForElementToDisappear(By locator) {
        wait.until(ExpectedConditions.invisibilityOfElementLocated(locator));
    }
    
    public void waitForTitle(String title) {
        wait.until(ExpectedConditions.titleContains(title));
    }
    
    public void waitForUrlContains(String urlPortion) {
        wait.until(ExpectedConditions.urlContains(urlPortion));
    }
    
    public void waitForCustomCondition(ExpectedCondition<?> condition) {
        wait.until(condition);
    }
}
```

### 7. Utility Layer — ExcelUtility

```java
public class ExcelUtility {
    
    private static Workbook workbook;
    private static Sheet sheet;
    
    public static Object[][] readExcelData(String filePath, String sheetName) {
        Object[][] data = null;
        
        try (FileInputStream fis = new FileInputStream(filePath)) {
            workbook = new XSSFWorkbook(fis);
            sheet = workbook.getSheet(sheetName);
            
            int rows = sheet.getPhysicalNumberOfRows();
            int cols = sheet.getRow(0).getPhysicalNumberOfCells();
            
            data = new Object[rows - 1][cols];
            
            for (int i = 1; i < rows; i++) {
                for (int j = 0; j < cols; j++) {
                    data[i - 1][j] = sheet.getRow(i).getCell(j).toString();
                }
            }
        } catch (IOException e) {
            System.out.println("Excel file read error: " + e.getMessage());
        }
        
        return data;
    }
    
    public static String getCellValue(String filePath, String sheetName, int row, int col) {
        try (FileInputStream fis = new FileInputStream(filePath)) {
            workbook = new XSSFWorkbook(fis);
            sheet = workbook.getSheet(sheetName);
            return sheet.getRow(row).getCell(col).toString();
        } catch (IOException e) {
            System.out.println("Error reading cell: " + e.getMessage());
            return null;
        }
    }
}
```

## 4. Environment and Runtime Configuration

- Keep environment-specific values outside test code.
- Typical properties: environment, base URL, browser, remote/local flag, timeouts and execution flags.
- The same test suite can run against stage/UAT/prod by changing configuration or runtime parameters.
- If different APIs/services have different URLs, maintain service-specific URLs rather than forcing one global base URL.

## 5. Driver Execution Flow

1. Execution starts locally or from Jenkins.
2. Environment and browser are selected from configuration/runtime parameters.
3. DriverFactory reads those values.
4. For local execution it creates the local WebDriver.
5. For remote execution it creates RemoteWebDriver against Selenium Grid/remote infrastructure.
6. BaseTest exposes the driver to the test lifecycle.
7. Page objects use the driver to perform UI actions.

## 6. CI/CD Flow

1. Code is pushed to Git.
2. Jenkins checks out the required branch/revision.
3. Jenkins passes parameters such as environment, browser and suite.
4. Maven resolves dependencies and builds the project.
5. The selected TestNG XML suite executes.
6. Configuration and DriverFactory prepare the execution environment.
7. Tests run locally or on the Docker/Selenium Grid infrastructure.
8. Reports, logs and screenshots are generated.
9. Jenkins archives/publishes the results and marks the build.
