- Purpose: TestNG-driven REST automation framework designed for reusable clients, data-driven suites and CI-friendly reporting.
- Tech stack: Java (21 in this module), RestAssured 5.x, TestNG 7.x, Allure, Owner for config, Lombok; Maven is used to build and run suites.
- Hybrid approach: supports API tests primarily, with ability to plug UI or BDD layers; supports data-driven, profile-based execution.
- Configuration: Owner/properties drive environment selection and baseURI; BaseTest or listeners apply RestAssured.baseURI and common RequestSpec.
- Reuse: RequestSpec/ResponseSpec, BaseClient, and utility libraries keep HTTP concerns centralized.
- Data-driven & CI: @DataProvider and external JSON files for test data; Jenkins/Docker run Maven suites, archiving allure results.
- Mapping & validation: Jackson POJOs and json-schema-validator standardize contract checks.
- Utilities: token management, retries, logging, awaitility and data generators are shared utilities.
- Flow (one-line): config -> BaseTest/listener -> Test -> Client -> RequestSpec -> RestAssured -> Response -> POJO/assertion -> Allure/Extent.
- Best practices: keep tests deterministic and idempotent, centralize environment configs and use reusable specs for consistency.
