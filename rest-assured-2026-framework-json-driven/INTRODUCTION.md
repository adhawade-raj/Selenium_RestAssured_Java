- Purpose: JSON-driven REST automation framework that externalizes scenarios and payloads to maximize coverage without code changes.
- Tech stack: Java 17, RestAssured 5.x, TestNG, Jackson, json-schema-validator, Allure; Maven-based build.
- Hybrid approach: data-first API testing with hooks to integrate BDD or UI tests; supports TestNG data providers and Cucumber where present.
- Data & loaders: JSON files (src/test/resources or data folders) map to POJOs via DataLoaders and feed TestNG @DataProvider.
- Reuse: RequestSpec/ResponseSpec patterns, BaseClient and shared utilities centralize HTTP concerns.
- Validation & mapping: Jackson mapping and JSON schema validation ensure expected contracts.
- Utilities: token managers, logging, retry/awaitility and generators are shared across tests.
- Flow (one-line): JSON -> DataLoader -> Test -> Client -> RequestSpec -> call -> Response -> POJO/assert -> report.
- CI & reporting: Maven + TestNG in CI; Allure stores request/response artifacts and test metadata.
- Best practices: keep JSON scenarios focused, version test data, and centralize environment configs to avoid hardcoded endpoints.
