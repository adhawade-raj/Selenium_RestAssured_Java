- Purpose: Selenium framework for Bookscart using PageObjects, BaseTest and TestNG to deliver maintainable UI tests.
- Tech stack: Java 17, Selenium 4.x, TestNG, JavaFaker; Maven as build tool.
- Hybrid approach: UI-first design with capacity to integrate API tests and data-driven strategies; supports modular page objects and utilities.
- Configuration: properties control environment, baseURL and browser; BaseTest initializes WebDriver and shared hooks.
- Reuse & pattern: BasePage for common actions, page classes model pages with methods that return next page objects for fluent flows.
- Data-driven: TestNG DataProviders or resource-based data drive scenario variations.
- Stability: explicit waits, retry utilities and WebDriverManager help reduce flakiness.
- Flow (one-line): config -> BaseTest -> Test -> Page -> Action -> Assertion -> Report.
- CI & reporting: Maven-based suites run in CI; listeners publish test artifacts to extent/allure outputs.
- Best practices: keep selectors centralized, avoid assertions in page methods, and prefer small, focused tests for reliability.
