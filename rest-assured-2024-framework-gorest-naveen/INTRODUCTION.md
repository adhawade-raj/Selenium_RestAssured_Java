- Purpose: practical RestAssured-based API automation framework focusing on reusability, readability and CI integration.
- Tech stack: Java (module-specific), RestAssured 5.x, TestNG, Jackson, json-schema-validator; Maven for build and dependency management.
- Hybrid approach: API-centric with easy hooks to integrate UI modules or BDD features; supports data-driven execution.
- Config & baseURI: environment properties/Owner classes supply baseURI and credentials; applied centrally in BaseTest or listeners.
- Reuse patterns: BaseClient/RestClient, RequestSpec/ResponseSpec and shared utilities to keep tests concise.
- Data & mapping: JSON-driven data, DataProviders, Jackson POJOs and schema validators for contract checks.
- Utilities & stability: logging, retry/awaitility, token refresh and random data utilities are shared across layers.
- Flow (one-line): config -> BaseTest -> Test -> Client -> RequestSpec -> call -> Response -> POJO/assertion -> report/artifacts.
- CI & reporting: Maven + TestNG in CI pipelines (Jenkins/Docker); Allure/Extent capture test artifacts.
- Best practices: centralize configs, keep tests small, prefer data-driven and reusable client methods.
